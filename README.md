# Rocket Hunt

A PWA game for kids aged 4–8. Players build a rocket from parts lying around, launch it to a planet, find treasures and bring them back to the rocket. The game has 20 planets, and each one is scored with 1–3 stars based on how fast the treasures were found.

- Made for iPad in landscape. Works on iPhone too.
- Uses almost no text: icons, arrows, glowing outlines and a pointing hand guide the player.
- All graphics are drawn in code on a canvas. All sound and music is synthesized with WebAudio. There are no asset files except the app icons.
- Progress is saved on the device in `localStorage`.
- Works offline once installed, using a Workbox service worker.

## Play

Live at https://robotman4.github.io/rocketgame/

To install on iPad or iPhone, open the link in Safari and choose Share → Add to Home Screen. It then runs fullscreen like an app.

## Develop

```bash
npm install
npm run dev      # dev server with --host, so a tablet on the same network can open it
npm run build    # production build into dist/
npm run preview  # serve the built version
```

Icons are generated by `python3 scripts/make_icons.py`, which needs Pillow.

## Deploy

`.github/workflows/deploy.yml` builds the game and publishes it to GitHub Pages on every push to `main` or `claude/**`. Pages must be switched on once under **Settings → Pages → Source: GitHub Actions**.

## Code layout

| File | What it does |
| --- | --- |
| `src/main.js` | Canvas, resizing, touch input, game loop, scene switching |
| `src/core.js` | Logical view size, math, easing, tweens, seeded RNG, colour helpers |
| `src/audio.js` | Chiptune music sequencer and sound effects |
| `src/draw.js` | Astronaut, bugs, treasures, rocks/bushes/?-blocks, flames, hint hand |
| `src/rocket.js` | Rocket part shapes (5 slots, 3–4 variants each, 9 colours) |
| `src/world.js` | Planet themes, terrain, parallax hills, decorations |
| `src/particles.js` | Smoke, sparks, stars, confetti |
| `src/scenes/*` | Title, map, build, flight, planet hunt, finale |

The game uses logical coordinates with a fixed height of 768. The width follows the screen aspect ratio: 1024 on iPad, about 1660 on iPhone.

## Difficulty curve

`levelSpec()` in `src/scenes/planet.js` sets the difficulty for each planet:

- 3 to 7 treasures per planet.
- More treasures are hidden under rocks, in bushes or inside ?-blocks as the planets go on.
- Beetles appear from planet 3 and flies from planet 6. Bugs bump the astronaut, who drops a treasure. Tap a bug to shoo it away.
- Planets 11–20 revisit the first ten themes at night.

Stars are based on time against a target time worked out from the level layout.
